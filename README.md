# Manny's Rentals Website

## Project Overview

Manny's Rentals is a simple car rental website created to introduce the
rental business, display available vehicles, and provide visitors with
contact and enquiry information. The website is focused on customers who
need transport while visiting KwaZulu-Natal or who need a rental
vehicle.

## Website Pages

-   **Home (`Index.html`)** -- Welcomes visitors and introduces Manny's
    Rentals.
-   **Information (`information.html`)** -- Displays example rental
    vehicles and their advertised weekly prices:
    -   Honda Civic -- R300 per week
    -   Hyundai i20 Automatic -- R330 per week
    -   Golf 7R 2018 -- R1,200 per week
-   **About (`about.html`)** -- Explains the business background and
    includes the rental policy.
-   **Contact Details (`contact details.html`)** -- Provides the
    business phone number, email address, and opening hours.
-   **Support (`Support.html`)** -- Provides support contact information
    and a message area.
-   **Enquiry (`enquiry.html`)** -- Contains a form for visitors to
    enter their details and select a vehicle category.

## Technologies Used

-   **HTML5** -- Structures the website pages and content.
-   **CSS3** -- Controls the website's layout, colours, navigation,
    buttons, and responsive styling.
-   **JavaScript** -- Adds behaviour to the enquiry form, including
    input validation and submission feedback.

## How to Run the Website

1.  Download or extract the project folder.
2.  Open the folder in Visual Studio Code or another code editor.
3.  Find `Index.html`.
4.  Open `Index.html` in a web browser. You can also use the VS Code
    Live Server extension.
5.  Use the navigation links to move between the website pages.
